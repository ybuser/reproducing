# 로컬 Qwen 7B와 논문 Qwen 72B: Base / CoT / TT 비교

2026-10-27. 로컬 실행 `bf16_official600_v1`의 완료 결과와 논문 arXiv v2의 ParaphrasedToMi 결과를 비교했다. TT는 fixed-4이며 adaptive-A는 포함하지 않는다. 공식 substring 채점 기준으로 로컬에서는 CoT가 가장 높고, 논문에서는 TT가 가장 높다.

## 먼저 집계 범위를 맞추기

논문 §3은 600문항과 all questions를 설명하지만, Table 2의 Avg는 참/거짓 믿음 점수의 평균과 일치한다. Table 6의 1차/2차 × 참/거짓 네 점수를 평균해도 같은 값이 반올림되어 나온다. 공식 코드도 이 집계를 `belief`로 저장한다. 따라서 아래 주 비교에는 로컬의 믿음 400문항(거짓200·참200)을 대응시켰다. **이는 코드와 표에 근거한 해석이며, 저자에게 분모를 확인한 사실은 아니다.** 전체600의 63.00/72.33/62.33을 논문 Avg와 바로 대조하지 않는다. [논문 v2 §3, Table 2·6](https://arxiv.org/html/2502.11881v2#S3).

## 주 비교: 공식 채점

| 방법 | 논문 Qwen 2.5 72B Avg | 로컬 Qwen2.5-7B 믿음400 | 로컬−논문 (%p) |
|---|---:|---:|---:|
| Base | 57.3% | 219/400 = 54.75% | −2.55 |
| CoT | 67.8% | 237/400 = 59.25% | −8.55 |
| TT / fixed-4 | 74.3% | 215/400 = 53.75% | −20.55 |

차이는 논문 Table 2의 공개된 반올림 값으로 계산했다. 저자의 원시 정답 수로 계산한 차이라고 해석하지 않는다.

| 구분 | 방법 | 논문 | 로컬 | 로컬−논문 (%p) |
|---|---|---:|---:|---:|
| 거짓 믿음 | Base | 39.0% | 69/200 = 34.5% | −4.5 |
| 거짓 믿음 | CoT | 63.0% | 80/200 = 40.0% | −23.0 |
| 거짓 믿음 | TT | 63.0% | 49/200 = 24.5% | −38.5 |
| 참 믿음 | Base | 75.5% | 150/200 = 75.0% | −0.5 |
| 참 믿음 | CoT | 72.5% | 157/200 = 78.5% | +6.0 |
| 참 믿음 | TT | 85.5% | 166/200 = 83.0% | −2.5 |

Table 6의 세부 유형과 로컬 결과를 더 나누면 다음과 같다. 각 칸은 **논문% → 로컬%**이며 로컬 각 유형의 분모는100이다.

| 질문 유형 | Base | CoT | TT |
|---|---:|---:|---:|
| 1차 거짓 믿음 | 22 → 38 | 50 → 35 | 65 → 35 |
| 2차 거짓 믿음 | 56 → 31 | 76 → 45 | 61 → 14 |
| 1차 참 믿음 | 85 → 73 | 84 → 87 | 91 → 86 |
| 2차 참 믿음 | 66 → 77 | 61 → 70 | 80 → 80 |

TT의 가장 큰 차이는 2차 거짓 믿음의 −47%p다. 반면 2차 참 믿음은 두 조건에서80%다. 이는 최종 답변의 유형별 차이이며 관측 추론·가설 전파·행동 평가 등 어느 내부 단계가 원인인지는 아직 확정하지 않았다.

## 각 실험 안에서 방법을 바꾼 효과

| 방법 간 차이 | 논문 공개 Avg 기준 (%p) | 로컬 믿음400 기준 (%p) |
|---|---:|---:|
| CoT − Base | +10.5 | +4.5 |
| TT − Base | +17.0 | −1.0 |
| TT − CoT | +6.5 | −5.5 |

로컬 TT는 Base 대비 참 믿음에서16개 더 맞혔고, 거짓 믿음에서는20개 덜 맞혀 순정답 수가4개 감소했다. 공식 채점에서의 관측 결과이며 유의성이나 일반적 성능 차이를 뜻하지 않는다.

## 전체600 및 별도 채점: 참고값

사실100·기억100을 포함한 전체600은 다음과 같다. 논문 Avg에 직접 대응시키는 값이 아니다. TT의 사실·기억200개는 공식 코드처럼 추적을 우회한다.

| 방법 | 전체600 공식 substring | 전체600 별도 final-only | 믿음400 별도 final-only |
|---|---:|---:|---:|
| Base | 378/600 = 63.00% | 344/600 = 57.33% | 196/400 = 49.00% |
| CoT | 434/600 = 72.33% | 379/600 = 63.17% | 208/400 = 52.00% |
| TT | 374/600 = 62.33% | 347/600 = 57.83% | 199/400 = 49.75% |

별도 채점은 논문 비교 표에 사용하지 않았다. 별도 믿음400 점수에서는 TT가 Base보다0.75%p 높으므로, "TT가 Base보다 낮다"는 설명에는 공식 채점 기준을 붙인다. 공식 채점은 최종 예측에 정답 문자열이 포함되는지를 검사한다. 모호한 답변 등을 구분하는 별도 판정과의 불일치172건 및 중간 추론 의미 검토가 남아 있다. 세 조건의 실행·형식 실패는0건이며 CoT 내부 호출1건은 잘렸다.

## 차이를 해석할 때의 조건

논문 Qwen 열은72B이고, ToMi 행동 표시는 GPT-4o-2024-08-06을 사용한다. 로컬은 Qwen/Qwen2.5-7B-Instruct를 행동 표시를 포함한 전 단계에 사용한다. 양쪽의 가설 수는4다. [논문 Table 2, Appendix B](https://arxiv.org/html/2502.11881v2#A2).

로컬은 Windows Transformers/BF16/SDPA이며 세 조건의 최종 답변 지시를 공통으로 유지했다. 공식 CoT/TT의 `Therefore` 접두어와 차이가 있다. 로컬 어댑터는 호출별 생성 인자를 반영하며 저자의 실제 backend 호출 설정과 완전한 일치는 미확인이다. 공식 코드 기본600개는 복원했지만 저자의 실제 실행 manifest와 개별 예측은 확보하지 못했다.

따라서 모델 크기·전처리 모델·프롬프트·backend·문항 차이를 분리할 수 없다. 위 격차를 모델 크기 하나의 효과, TT 알고리즘의 일반적 실패, 또는 논문 수치 재현의 성공/실패로 판정하지 않는다. 모델이나 설정을 바꾸는 추가 실행은 이 비교 작업에서 하지 않았다.
