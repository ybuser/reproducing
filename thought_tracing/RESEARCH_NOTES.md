## 논문·구현·해석의 구분

논문은 Hypothesis-Driven Theory-of-Mind Reasoning for Large Language Models, arXiv v2를 우선했다. baseline은 공식 commit `966eb2712714aa29b4d5d2395e39af94a2be90d7`의 TT를 재사용한다. 로컬 모델 연결/호환성(A)과 로깅/평가(B)를 분리했으며 fixed-4에 알고리즘 변경(C)을 적용하지 않았다. 실제 adapter의 생성 설정 반영 및 공통 최종 답변 지시 등 출력에 영향을 줄 수 있는 차이는 기록했다.

코드에서 이전 가중치는 평가 softmax에 곱해지는 누적 Bayesian prior로 사용되지 않는다. 현재 평가 점수의 softmax로 교체된다. fixed-4의 재표집/재표현 분기는 그대로이며, adaptive-A는 별도 방법으로 이를 비활성화했다. 이 설명은 코드 동작이며 사람의 실제 사고 과정에 대한 증거가 아니다.

이번 로컬 결과는 Qwen2.5-7B 단일 모델을 모든 단계에 사용한 것이다. 논문 Qwen2.5-72B + GPT-4o 행동 표시 구성과 다르다. Base/CoT는 원문, TT/adaptive는 행동 표시·관측 전처리 경로를 사용한다. 논문 전체 평가·전체 벤치마크 재현으로 부르지 않는다. 고정 600개는 공식 기본 선택 재구성이며 저자 실행 manifest와의 동일성은 미확정이다.

가설별 상대 가중치와 ESS/유사도/요약 top-p를 확률의 절대 보정 또는 의미적 다양성 보장으로 해석하지 않는다. adaptive-A의 개별 가중치 threshold 삭제는 누적 top-p와 다르다. 가변 초기 개수·삭제·재표집/재표현 제거·state-only 평가가 함께 바뀌었으므로 pruning의 단독 효과를 분리하지 못한다.

## 결과와 근거

전체 600문항 공식 정답은 Base 378, CoT 434, TT 374, adaptive-A 374다. adaptive-A의 5개 형식 실패를 분모에 포함했다. 최종 답변 별도 채점은 각각 344, 379, 347, 342다. 상세 표·토큰·시간·자원 측정 한계는 `reports/FINAL_600_COMPARISON_KO.md`에 있다.

증거를 갖춘 검토 후보는 행동/문맥 표시(row 5979), 2차 믿음의 소실(row 4101), 정답을 맞혔으나 중간 상태가 의심되는 경우(row 976)다. 모델 크기만으로 인과 원인을 확정할 수 없다. 저자 질문은 기존 초안의 최대 3개를 유지하고 연락하지 않았다.

## 공개 사본의 안전성과 이동

모델/환경/인증서/사내 환경 덤프/PDF/기존 Git 객체는 제외했다. 공개 원본의 사용하지 않는 MMToM 스크립트에 있던 인증정보 형태 문자열을 사본에서 제거했고, 원래 소스와 실행 로그는 로컬에서 보존했다. 제거한 사본의 경로와 전후 hash만 `records/publication_redactions.json`에 있다. 이 한 파일의 공개 사본은 과거 frozen hash와 다르므로 옛 실행을 그대로 재개하는 방식으로 다루지 않는다. 현재 ToMi 실행 경로와 결과는 바꾸지 않았다.

현재 미완료 GPU 문항은 없다. 다른 PC에서는 먼저 `tools/backup.py`로 검증·복원·분석한다. 새 GPU 실행은 새 run ID와 환경 snapshot을 사용한다. 가정용 3080 10GB의 4비트 실행은 BF16과 별도 조건이다. 정확한 명령과 주의점은 `CONTINUE_ON_ANOTHER_PC_KO.md`를 따른다.
