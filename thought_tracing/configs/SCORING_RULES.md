# 파일럿 출력 확인 전 채점 규칙 (v1)

확정 시점: 2026-10-20, 모델 최초 로딩·생성 전. 변경 시 기존 결과를 보존하고 새 평가 버전을 사용한다.

1. **공식 점수**: 공식 `test_tomi.py:219`와 동일하게, 정답 문자열(underscore를 공백으로 치환)이 **최종 답변 호출 출력**에 대소문자 무시 substring으로 존재하는지 판단한다. 중간 CoT/TT 출력은 채점하지 않는다.
2. **별도 보수적 점수**: 최종 호출 출력만 검사한다. 공개 test 정답 어휘 중 해당 원문 이야기에서 등장하는 위치 후보를 어휘 경계로 찾는다. 정답 후보 하나만 명시하고 한 문장으로 답했으며 모호함·부정·양자택일 표현이 없을 때 자동 정답으로 센다. 후보 어휘는 모델 입력에 넣지 않는다.
3. 복수 후보, 답변 없음, 후보를 못 찾은 답변, 복수 문장, `or/either/and/but/whereas/however/maybe/might/perhaps/probably/uncertain/unknown/not/cannot/can't/don't/doesn't` 등의 모호함·부정·병렬 표현 또는 comma/semicolon은 **사람 검토 필요**(`null`)로 표시하고 자동 정답 수에 포함하지 않는다. 정답 하나를 포함했다고 자동 통과시키지 않는다. room 두 개를 병렬 언급하는 경우도 이 검토 규칙에 포함한다. “and”나 “not” 또는 comma가 정상 문맥에서 쓰이는 경우도 사람이 재검토한다. 모든 가능한 의미 충돌을 어휘 규칙으로 보장해 검출할 수 있다고 주장하지 않는다.
4. 어휘가 서로 포함되면 가장 긴 후보부터 찾고 그 구간을 가려 중복 탐지하지 않는다. 같은 후보의 반복은 하나로 센다. 앞의 `Answer:`와 Markdown 강조 표시는 채점용 표면 정규화에서 제거할 수 있으나 원시 출력은 보존한다.
5. 한 후보만 명확히 말했지만 정답과 다르면 별도 오답이다. 출력이 상한에서 종료되었으면 최종 답변을 확정하지 않고 사람 검토 대상으로 남긴다.
6. 실행 실패·형식 실패를 분모에서 제외하지 않는다. 전체 분모는 조건별 20이다. 자동 점수와 사람이 검토한 의미적 판정은 구분한다. 이 어휘 기반 규칙도 의미를 완전하게 판정하지 못하므로 모든 원시 답변을 검토 가능하게 보존한다.
7. 결과 보고에는 공식/별도 채점 불일치와 미검토 항목을 전부 나열한다. 중간 추론 검토는 정답 여부와 별개이며, 검토하지 않은 trace를 검토 완료로 표시하지 않는다.

이 표본은 사실·기억 질문을 포함하는 논문 전체 평가와 다르다. Base/CoT/TT의 계산량은 다르며 이 20개에서 통계적 우월성을 주장하지 않는다.
